# 공개 전 개인정보·보안 점검

점검일: 2026-09-11. 최초 검토 버전: `74c075f`. 수정 버전: **0.1.1**.

소스 검토에서 발견한 작업 폴더 밖 저장 문제 2건을 수정했습니다. 공개 대상의 개인정보·인증정보 검사에서는 제거가 필요한 항목을 발견하지 못했습니다. 이 기록은 아래 범위에서 수행한 점검 결과이며, 모든 취약점이나 개인정보의 부재를 보증하지 않습니다.

## 발견한 문제와 수정

두 문제는 로컬 사용자가 외부에서 받은 작업 폴더를 처리할 때 발생하는 중간 심각도의 파일 저장 경계 문제였습니다. 원격 서비스나 코드 실행 경로는 확인되지 않았습니다.

| 문제 | 수정 | 근거 |
| --- | --- | --- |
| 저장된 `asset_id`를 조작하면 PSD가 작업 폴더 밖에 저장됨 | `job.json`을 읽을 때 식별자를 다시 검증하고 PSD 경로의 실제 위치도 검사 | 잘못된 상대/절대 경로·Windows 예약 이름·빈 값 등을 archive/build/verify에서 거부하는 테스트 |
| 작업 폴더 아래 링크가 archive/build 출력을 외부로 우회시킴 | 생성 폴더와 PSD를 포함한 모든 출력 위치를 쓰기 전에 검사. 관리되는 읽기 경로도 검사 | 수정 전 Windows 정션을 통해 외부 생성이 발생했으며, 같은 테스트가 수정 후 통과 |

독립 소스 재검토에서도 두 수정에 구체적인 우회나 새 회귀가 발견되지 않았습니다. 이는 다른 프로세스가 검사 직후 경로를 교체하는 동시 변경까지 막는 원자적 파일 시스템 보장은 아닙니다.

## 의존성

로컬 가상환경의 `pip 24.0`, `setuptools 65.5.0`에서 알려진 보안 권고를 확인하여 각각 **26.2.1**, **84.0.0**으로 업데이트했습니다. 빌드 의존성의 setuptools 하한과 설치 안내도 수정했습니다. 이 변경은 저장소의 전용 가상환경에 적용했습니다.

업데이트 후 공개 패키지 이름·버전 16개를 [OSV 공식 API](https://google.github.io/osv.dev/post-v1-querybatch/)로 다시 조회하여 알려진 취약점 일치 **0건**을 확인했습니다. 패키지 버전 정보만 전송했으며 저장소 코드나 제작 자료는 전송하지 않았습니다. 새로 발견되는 취약점이나 미등록 취약점까지 포함한 보증은 아닙니다.

## 실행 검증

Windows / Python 3.11.9 / Pillow 12.3.0 / psd-tools 1.18.0에서 확인했습니다.

- `pip install -e .`: 0.1.1 설치 성공.
- `pip check`: 의존성 충돌 없음.
- 단위·회귀 테스트: **18개 중 17개 통과, 1개 스킵**.
- 실제 Windows 정션을 이용한 archive·build 출력 부모 3종·verify 경로 차단 통과.
- 파일 심볼릭 링크 생성 권한이 없어 dangling PSD 링크 테스트 1개는 스킵. 차단 경로는 소스로 확인했지만 이 환경에서 실행 검증했다고 주장하지 않습니다.
- 합성 데모와 설치된 CLI verify: **24개 파일 무결성 및 3개 레이어 PSD 검사 통과**. 밝고 어두운 배경 합성 최대 채널 차이 1, 알파 차이 0.
- 기존 생성물·게임 사례 파일의 내용 변경 없음. 이미지 생성 API 호출 없음.

## 남는 신뢰 조건

입력 JSON은 외부 파일을 가져올 수 있고 `processing_files`에는 임의 파일을 지정할 수 있습니다. 프롬프트·분석·메모·이미지 메타데이터도 자동 익명화하지 않습니다. 외부 작업 폴더와 입력 경로를 검토하고, 한 작업 폴더에는 한 작업자만 쓰세요. 전체 자원 사용량 제한이나 다중 사용자 샌드박스는 제공하지 않습니다.

이번 점검은 macOS/Linux 실행, Photoshop GUI 호환성, 새 게임 적용이나 개발사의 공식 승인을 검증하지 않습니다. 해당 범위는 [기존 검증 기록](verification.md), [보안 정책](../SECURITY.md), 각 사례 설명을 따릅니다.
